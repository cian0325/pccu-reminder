# 課輔提醒 PWA（文大課輔系統）

在 iPhone 上提醒：**作業截止時間、下一堂課的時間與教室、新公告**。
本專案為寒假書審作品，後端核心以 **C++17** 實作。

## 這個 repo 的結構

GitHub Pages 直接發佈根目錄，所以網站檔案（`index.html`、`app.js`… 與 `icons/`）放在最上層；
文件裡提到的 `pwa/` 指的就是根目錄。

| 位置 | 內容 |
|---|---|
| 根目錄 | PWA 網站（GitHub Pages）：`index.html` `app.js` `style.css` `data.js` `calendar.js` `sw.js` `manifest.webmanifest` `icons/` |
| `server-cpp/` | C++17：`pccu_parser.cpp`（課表、首頁、作業截止時間解析）、`reminder_planner.cpp`（提醒排程） |
| `crawler/` | 爬蟲：`crawl_in_browser.js`（在瀏覽器窗格執行）、`build_sync.py`、`pccu_crawler.py`（Playwright 版） |
| `tools/` | `build_artifact.py`：組成 Claude 網頁版單一檔 |
| `tests/` | 測試；模擬網站與測試頁面內容全為虛構 |

在這個 repo 執行測試時，把 `pwa` 換成 `.`，例如 `node tests/smoke.js .`。

## 互動功能

| 功能 | 說明 |
|---|---|
| 標記完成 | 作業前的核取方塊；完成後不再提醒，並記錄完成時間供統計 |
| 貪睡提醒 | 「1 小時後再提醒」；到期後補發一則通知 |
| 每日總覽 | 每天設定時間（預設 07:30）推送今日課程與 24 小時內截止作業；超過 3 小時不補發 |
| 優先度排序 | 依剩餘時間、重要標記與進度計算，左側顏色條標示高／中／低 |
| 導航到教室 | 下一堂課卡片可開啟 Apple 地圖，搜尋「中國文化大學 + 館名」 |
| C++ 進度追蹤 | 未開始／寫程式中／除錯測試／整理繳交 四個階段，附進度條與備註 |
| 週統計 | 本週每天完成數、提早完成比例、最後 24 小時才完成的份數 |
| 通知深連結 | 點通知會直接跳到該作業 |

優先度公式（前端 `priorityScore()` 與 C++ `priorityScore()` 相同）：

```
分數 = 100 × e^(−剩餘小時 / 72)    （已逾期 = 100）
分數 ×= 1 − 0.3 × 進度%
分數 += 25                          （標為重要）
```

**資料來源說明**：App 內建的示範資料是虛構的（課程、教室、作業都不是真的），首頁會顯示橫幅提醒。
串接課輔系統之前，請到「設定 → 管理我的課程與作業」輸入自己的資料；輸入的項目會自動歸入目前學期。

未實作：**多人協作**（與同學共用作業清單）。需要帳號系統與資料庫，且會涉及他人資料，列為未來擴充。

## 兩種用法

| | Claude 網頁版（Artifact） | App 版（GitHub Pages） |
|---|---|---|
| 怎麼更新作業與公告 | 跟 Claude 說「幫我爬蟲」，打開頁面就是最新 | 在電腦執行爬蟲，把 my-data.json 匯入 |
| 手機系統通知 | 不支援（提醒顯示在畫面上） | 支援（App 開著時） |
| 加入主畫面、離線 | 不支援 | 支援 |
| 誰看得到資料 | 只有你（需登入 Claude；資料庫規則只允許擁有者讀寫） | 只在你的手機上 |

兩個版本是同一份程式碼：`python3 tools/build_artifact.py` 把 `pwa/` 組成單一檔 `dist/pccu-reminder.html` 發佈成 Artifact；
`app.js` 偵測到 `window.claude` 就啟用雲端同步，並把 alert/confirm/prompt 換成頁面內的提示（Claude 網頁不顯示這些對話框）。

### 「幫我爬蟲」的流程

```
你：「幫我爬蟲」
Claude ─▶ 你電腦上 Claude 桌面 App 的瀏覽器窗格（你自己登入過課輔系統）
       ─▶ 執行 crawler/crawl_in_browser.js：讀首頁課程、公告內文；用同網站的隱藏 iframe 讀 13 門課的作業頁（約 1 分鐘）
       ─▶ C++ pccu_parser homework 判斷截止時間 ─▶ crawler/build_sync.py 組成同步資料
       ─▶ 寫進 Artifact 資料庫 sync/latest ─▶ 手機上的頁面即時更新
```

需要：電腦開著、Claude 桌面 App 開著，且瀏覽器窗格裡的課輔系統還在登入狀態（過期時 Claude 會請你重新登入）。
你在手機上標的完成、重要、進度、備註存在那支手機，不會被同步覆蓋。

## 系統架構

```
 iPhone (PWA)  <──Web Push──  Node 推播服務  <──提醒清單──  C++ 後端
     │  ▲                                                      │
     │  └────── /api/summary（課表、作業、公告）────────────────┤
     │                                                         ▼
     └────────── 訂閱推播 (endpoint) ────────────►  定時登入、解析課輔系統 HTML
```

為什麼需要後端：
1. PWA 受瀏覽器 CORS 限制，無法直接讀取學校網站。
2. 課輔系統需要登入，帳密不能放在前端。
3. iOS 要在 App 關閉時也收到通知，只能靠後端送出 Web Push。

## 執行第一階段

PWA 必須在 **HTTPS** 下才能安裝與使用通知（本機測試 `localhost` 除外）。

本機預覽：

```bash
cd pwa
python3 -m http.server 8080
# 瀏覽器開 http://localhost:8080
```

放到 iPhone 上測試的最簡單方式是部署到 GitHub Pages（自動 HTTPS）：
把 `pwa/` 資料夾內容推到一個 repo，Settings → Pages 選 main 分支即可。

iPhone 安裝步驟（iOS 16.4 以上）：
1. 用 **Safari** 開啟網址
2. 分享 → **加入主畫面**
3. 從主畫面圖示開啟 → 設定 → 開啟通知 → 傳送測試通知

> 一般 Safari 分頁收不到推播，只有從主畫面開啟的 PWA 可以。
> iOS 的網頁通知不支援「通知上的按鈕」，所以貪睡改為在 App 內操作。
> 目前的提醒只在 App 開啟時由前端觸發；App 關閉後的推播需要第三階段的後端。

## C++ 提醒核心

`server-cpp/reminder_planner.cpp`：輸入作業、課表、提醒設定，輸出依時間排序的提醒清單。

```bash
cd server-cpp
g++ -std=c++17 -Wall -Wextra -Wno-missing-field-initializers -O2 reminder_planner.cpp -o reminder_planner
./reminder_planner
```

目前包含：`planAll`（提醒排程）、`priorityScore`（優先度）、`buildDailyBrief`（每日總覽）、`currentSemester`（學期判斷）。

設計重點（可在書審說明）：
- 只處理目前學期，舊學期（114-1、114-2…）的資料與提醒一律略過
- 每則提醒有唯一 `key`，避免重複推播
- 已錯過的提醒只補送最接近截止的一則
- 已完成、已逾期的作業不提醒
- 只用標準函式庫，附自我測試

## 學校行事曆

`pwa/calendar.js` 收錄 [115 學年度行事曆 PDF](https://www.pccu.edu.tw/calendar/old_calendar/115calendar.pdf) 的 70 筆事件（日間部），事件名稱照原文。
PDF 是掃描圖片、沒有文字層，所以是逐筆人工整理，並用程式核對每個日期的星期幾與 PDF 月曆一致。

| 功能 | 說明 |
|---|---|
| 行事曆頁 | 「課表 → 學校行事曆」，依月份分組，可篩選停課／考試／選課／截止 |
| 停課日 | 放假、補假、全校休假當天不顯示下一堂課、不發上課提醒；週課表把當天課程劃掉並標示原因 |
| 寒暑假 | 只在上課期間（第 1 學期 9/14–1/17、第 2 學期 2/22–6/27）提醒上課 |
| 首頁 | 「近期行事曆」顯示 30 天內的 3 筆事件 |
| 每日總覽 | 今天停課會註明原因，並列出今天與明天的行事曆事件 |
| 提醒 | 考試、選課、截止、停課事件前一晚 19:00 後提醒一次；當天開 App 會補發 |
| 對象 | 只適用研究生、應屆畢業生的事件加上標籤，不出現在首頁與提醒 |

整理時的判斷（以學校公告為準）：
- 上課期間的結束日取第 18 週最後一天，**包含彈性教學週**（第 17–18 週）。如果你的課在彈性教學週不上課，這兩週會多出上課提醒。
- 期末考試週的附註「1/1 放假之考試延後至 1/8」「6/9 端午節放假之考試提前至 6/2」另外列成事件，標示「依附註整理」。
- 11/7（六）校友返校節、6/5（六）畢業典禮寫的是「上班一天」，不是補課，所以沒有設定成補課日。
- 行事曆資料格式也支援補課日（`followsWeekday`），本學年度沒有用到。

C++ 端：`reminder_planner.cpp` 的 `Settings` 新增 `noClassDates`、`termStart`、`termEnd`，`nextOccurrence()` 會跳過停課日與學期以外的日期（最多往後找 8 週，跨過連假）。

## 解析器（pccu_parser）

`server-cpp/pccu_parser.cpp` 把兩個頁面轉成 App 可用的資料。純 C++17 標準函式庫，用字串掃描而非 regex（實際頁面含大量內嵌 CSS，`std::regex` 在大字串上容易堆疊溢位）。

```bash
cd server-cpp
g++ -std=c++17 -Wall -Wextra -O2 pccu_parser.cpp -o pccu_parser
./pccu_parser schedule  課表.html            # 學生課表查詢 → 上課時段
./pccu_parser dashboard 首頁.html            # 課業輔導系統首頁 → 課程、公告、作業
./pccu_parser import    課表.html 首頁.html > my-data.json   # 產生 App 可匯入的檔案
```

把 `my-data.json` 匯入 App：**設定 → 管理我的課程與作業 → 匯入資料**，選擇檔案或貼上內容。
匯入會取代同學期的課表與公告；作業只新增、不覆蓋。

設計重點：
- 課表是節次格狀表格，同一堂課連續多節會合併成一個時段（例如第 5–7 節 → 12:10–15:00）
- 課名欄位格式不固定（`資工系 2A 6277 …`、`優質生活2 Y285 …`、`體育 0 9008 … (01)`），以「第一個 3 碼以上英數字」辨認課號
- 教室 `大義      0721` 正規化為 `大義館 0721`；體育等課頁面沒有教室，保留空字串，App 顯示「教室未標示」
- 保留課輔系統的課程代碼（`ccode`），之後可對應作業與公告
- 學期代碼 `1151` → `115-1`，與 App 的學期過濾一致
- 不讀取、不輸出頁面中的學生姓名與學號

**注意**：`my-data.json` 含你的個人課表，**不要放進公開的 GitHub repo**。

### 作業截止時間

首頁的「最新作業」只列 5 筆，而且括號內的日期分不出是截止日還是發布日，所以 `import` 不匯入作業。
作業改由爬蟲逐一讀取各課的「作業」頁，再用 `pccu_parser homework` 判斷截止時間，見 [crawler/README.md](crawler/README.md)。

```bash
./pccu_parser homework 作業列.txt     # 每行：課程代碼<TAB>課程名稱<TAB>列文字（欄位以 " | " 分隔）
```

## 爬蟲與公告內文

`crawler/pccu_crawler.py`（Python + Playwright）在你自己的電腦上執行：你登入一次，之後它用同一個瀏覽器工作階段讀取每門課的作業頁與公告內文，
輸出 `my-data.json` 給 App 匯入。分工是「Python 負責操作瀏覽器、C++ 負責解析」：作業截止時間的判斷全部在 `pccu_parser.cpp`。

- 不保存帳號密碼；登入 Cookie 存在 `~/.pccu-crawler/`（權限 600）
- 判斷不出截止時間的作業不會產生提醒，寫進 `crawl-report.txt`
- App 匯入時，爬到的作業取代上一次爬到的作業；作業 id 每次相同，所以 App 裡的完成、重要、進度都會保留
- 公告點開是底部彈出的內文頁：內文只當純文字顯示（不執行學校頁面的 HTML），網址自動變成連結，只允許 http/https 連結
- 設定頁顯示上次同步時間；超過 36 小時沒同步，首頁會提醒

詳細的安裝、第一次登入、排程與判斷規則見 [crawler/README.md](crawler/README.md)。

## 安全與使用規範

- 課輔帳密只放在後端環境變數或加密設定檔，**不要**放進前端或 git
- 抓取頻率保持低（例如每 15–30 分鐘一次），避免造成學校系統負擔
- 使用前請確認學校對自動化存取的規定；書審展示建議使用示範資料或自己的帳號
- 這個 App 只供本人使用，不收集他人資料
